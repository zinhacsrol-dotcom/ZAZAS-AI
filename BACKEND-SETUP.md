
# ZAZA'S AI — Configuração do servidor

Este projeto utiliza uma função de servidor para conectar o chat à API da OpenAI.

## Requisitos

- Uma hospedagem compatível com funções Node.js.
- Uma conta de API administrada por um responsável adulto.
- Um modelo de IA disponível na conta.

## Variáveis de ambiente

Configure estas variáveis no painel privado da hospedagem:

- `OPENAI_API_KEY`: chave secreta da API.
- `OPENAI_MODEL`: identificador do modelo disponível.

## Segurança

- Nunca coloque a chave da API no HTML ou JavaScript do navegador.
- Nunca publique a chave no GitHub.
- Não compartilhe a chave em mensagens.
- Configure limites de uso e acompanhe os custos.

## Importante

O GitHub Pages hospeda páginas estáticas e não executa esta função de servidor. É necessário publicar a função em uma hospedagem compatível antes de conectar o chat.
